## 現行の既定経路

`npm run dev` は `src/index.ts`、`npm start` は `dist/index.js` を起動します。どちらも `createApplication()` から `createPlayerApplication()` へ進み、同一Node.jsプロセス内に既定の自律プレイヤーを構成します。文書上の制御は、owner会話と目的提案を扱う `PlayerConversationAgent`、観測・記憶・技能から行動を選ぶ `PlayerPurposeAgent`、決定・中断・再判断を扱う `PlayerRuntime`、ゲーム操作と前後観測を担う `PlayerBody` に分かれています。会話と目的判断は別のResponses呼出しです。

旧helperのコードも残っています。設計文書は `src/skills`、`src/decision`、`src/reflexes`、旧tool実行経路を既定Playerとは区別しています。したがって、削除対象や統合方法はまだ決めません。
