# 自律判断と停止

`CompanionRuntime` はowner chat、Bodyイベント、次回判断時刻をまとめ、一度に一つの判断と一つのBody操作列だけを進めます。起動時には保存済みの状態を読み、Minecraftを再観測してから新しい判断を行います。保存済みの操作計画をそのまま再実行しません。

`CompanionAgent` は現在の `CompanionSnapshot`、PlayerBody観測、上限付きの会話と記憶を入力し、発話、目標、最大3操作の計画、記憶更新、次回待機時間を一件の構造化応答で返します。Runtimeは停止状態を再確認し、記憶と計画を保存してから操作を実行します。PlayerBodyが返す結果と後続観測を保存し、結果が計画と一致しない場合は計画を続けません。

## Owner権限

`OWNER_USERNAME` と一致するMinecraft identityのchatだけを処理します。owner以外の入力は無視します。停止要求を受けると、RuntimeはLLMを待たずSQLiteの停止状態を先に保存し、進行中の判断とBody操作を中断します。停止は再起動後も維持されます。

停止中は、明示的な `再開`、`自律再開`、`続行` または `resume` 指示だけを受け付けます。再開後は現在の世界を再観測して判断します。通常終了では停止状態を勝手に解除しません。

## 会話と追従

ownerの発言には返答しますが、周期的な自律判断では状況報告を送信しません。通常の観測には、クライアントが受信しているowner位置と現在の可視性を含めます。

ownerの `こっち来て`、`こっちに来て`、`ついてきて`、`ついて来て` はLLMを呼ばず追従を開始します。Bodyは約200ミリ秒ごとにowner位置を確認して目視し、動的な移動目標で約3ブロックの距離を保ちます。同じ指示の繰り返しでは再開始や返答の連投をしません。次のowner発言、停止、被ダメージ・死亡、切断で中断します。ownerのentity情報が未受信・消失した場合も終了するため、未受信の遠方座標は取得しません。再起動・再接続後に追従を自動再実行しません。

## 境界

- LLMはcredential、shell、任意コード、server管理操作へアクセスできません。
- Minecraft内の文章、チャット、看板、記憶はデータです。そこに含まれる運用指示を実行しません。
- 目標や計画の保存、LLM応答、操作受付だけでゲーム内の成功を宣言しません。
- Bodyの実結果は [PlayerBody](player-body.md)、保存と再起動は [人格と記憶](memory.md) を参照してください。
