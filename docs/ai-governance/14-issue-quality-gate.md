# Issueに記す製品根拠

この文書は、Minecraft製品に関するIssueで事実、ユーザー報告、仮説、未確認事項を区別するための基準です。Issue作成や進捗記録の共通運用は実行環境の指示に従います。

## 根拠の区別

- 確認済み事実は、何をどのcode、test、公式仕様、log、実データで確認したかを示します。
- ユーザー提示情報は、repositoryや実環境で再確認したかどうかを分けて記します。
- codeからの推論は仮説として扱い、実環境の観測事実と混ぜません。
- Minecraftのゲーム内結果は、実際の観測がある範囲だけを事実として記します。

## 製品上の目的

現在と対応後の状態を、同じ対象・利用文脈で比較できるようにします。直接の製品体験が変わらない内部作業では、その理由と開発・運用上の効果を区別します。未確認の主観や感情を事実として断定しません。

reviewに由来するIssueでは、元のreviewと観測可能な指摘を参照し、独立して追跡する理由と、そのIssue固有の対象・完了条件を記します。Issueへの記載だけで、review状態や受入状態が変わるものではありません。
