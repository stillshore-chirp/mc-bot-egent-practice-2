# 小規模拠点の設営契約

Issue #25 の拠点設営は、認証済みの利用者が家・拠点の建築を明示して任せた場合に限る。一つの依頼は一つの設営作業であり、Bot が場所と工程を決める。状態質問、状態の自動再評価、第三者の発話からは建築しない。

## 既定の範囲

- 平坦で乾いた、現在地付近の 3×3 区画を候補とする。地面は観測済みの支持ブロックとし、周囲一ブロックの空間、既存ブロック、液体、危険、他プレイヤー、登録済み拠点・収納先に接する区画は使わない。地面の素材名だけで自然由来を証明したとは扱わない。
- 3×3 の壁二段、出入口一か所、屋根一段の小屋を一つ作る。設置は最大 23 ブロック、採取は不足分の原木だけ、移動と探索は設定された距離上限の内側に制限する。
- 材料は既定でオークの板材とする。手持ちの板材を先に使い、不足分だけオークの原木を保護判定済みの自然木から収集してクラフトする。他者のチェストや登録済み収納先から資材を取り出さない。
- 利用者が別の場所、規模、材料、保護範囲、上限を指定した場合、対応できる条件かを変更前に判定する。安全な既定値へ読み替えられない条件だけを具体的に確認し、無断で範囲を広げない。

## 工程と再開

候補地確認、資材見積り、許可済み採取、クラフト、各ブロック設置、全体照合を別の工程として記録する。採取と設置の前に保護判定を取り直し、設置直後にサーバー上のブロック状態を照合する。危険、切断、停止、在庫不足、保護対象、照合失敗では後続の変更を止め、完成済み箇所と未完成箇所を分けて知らせる。

再開時は保存済みの設計と同一 world・区画を再観測し、既に設置された箇所だけを進捗として数える。異なるブロックがある箇所を上書きせず、資材不足なら残りだけを調達する。全箇所をサーバーとゲーム内で確認できるまで「完成」としない。登録拠点や指定チェストは既存の登録操作だけで変更でき、建築完了だけで自動登録しない。

実際のプレイ world では、区画と影響を特定した許可なしに試験建築をしない。自動テストと許可済みの隔離テスト world で、完成、資材不足、保護、停止、再開を確認する。
