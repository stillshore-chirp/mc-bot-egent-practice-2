# mc-bot-egent-practice-2

Minecraftの世界に実体を持ち、プレイヤーと自然言語で会話し、ゲーム内で行動できる単一のAIコンパニオンを構築するプロジェクトです。

## プロジェクトの目的

AIコンパニオンが、Minecraft内で観測した状況とプレイヤーとの継続的な関係を基に、安全に会話・判断・行動できる状態を目指します。

## 目指す理想

- 安定した名前、人格、価値観、話し方を持つ。
- プレイヤーとの関係、共有した出来事、約束、世界内の場所や経験を継続的に記憶する。
- 再起動やセッションをまたいでも、同じ存在として振る舞う。
- 行動は中断可能で、安全境界と失敗時の回復手段を持つ。
- Minecraft上で実際に観測された状態を、成功や失敗の正本とする。
- LLMは会話や高水準の判断へ使い、即時性や安全性が必要な処理は決定論的な実行機構で扱う。
- 個人開発で維持できる、単純で検証可能な構成を優先する。

## 初期目標

- Minecraftへの接続と自然言語での会話
- プレイヤーへの追従と即時停止
- 空腹、危険、攻撃などへの即時対応
- プレイヤー情報、場所、約束の永続記憶
- 複数工程を含む一つの作業の実行
- 実際のゲーム状態による作業結果の検証

これらは今後の目標であり、現時点で実装済みの機能ではありません。

## 非目標

- 旧リポジトリとの互換性維持や、旧アーキテクチャ・コードの移植
- 最初から研究用ベンチマークや汎用エージェント基盤を構築すること
- 最初からVPT、MineDojo、複数エージェントを導入すること
- 初期ルール・文書基盤の整備段階で製品コードを実装すること
- 製品実装に先行して使用言語、フレームワーク、ライブラリを固定すること

## 現在の状態

現在は第1段階として、プロジェクト定義、エージェントルール、共同作業文書、機械検証だけを整備しています。Minecraftボット、LLM連携、記憶機構、ゲーム操作、サーバー連携の製品コードと実行環境はまだありません。

第2段階でアーキテクチャを設計し、その設計に基づいて製品実装を開始します。
